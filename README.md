# MKVToolNix Batch by Wellan

MKVToolNix Batch by Wellan is an unofficial modified build of MKVToolNix GUI based on MKVToolNix v100.0.

The original MKVToolNix application is available here:

https://mkvtoolnix.download/downloads.html

## What this build adds

This build adds a Batch workspace to MKVToolNix GUI. It is designed for users who work with multiple MKV files at once, such as TV seasons, anime seasons or folders containing episodes with similar audio and subtitle tracks.

The Batch tools help you:

- Analyze multiple MKV files together.
- Use one file as a global model.
- Compare audio, subtitle and video tracks against that model.
- Quickly keep, remove or exclude tracks across many files.
- Edit track language, track name, default flag and forced flag.
- Rename files in bulk before remuxing.
- Queue multiple remuxing jobs faster than editing files one by one.
- Skip remuxing when no actual change is needed.

The goal is to make repeated MKV remuxing safer, faster and easier.

## How to start the application

Open:

```text
Code\mkvtoolnix-gui.exe
```

The main folder also contains the standard MKVToolNix documentation and license files.

## Important notes

- This is not the official MKVToolNix release.
- This project is based on MKVToolNix v100.0.
- MKV files are remuxed, not re-encoded.
- Remuxing should not change video or audio quality by itself.
- Always test on a small set of files before processing a full library.
- Keep backups of important files, especially when using source-file replacement.
